## 📋 جدول الأيام

### اليوم الأول: الناصرة → قلعة الحصن
- رحلة سهلة تعريفية
- الاستعدادات الأولية
- التعرف على الفريق والمعدات

### اليوم الثاني: قلعة الحصن → سد المزينة
- مسار جبلي متوسط
- زيارة موقع أثري مهم
- الاستراحة والتخييم

### اليوم الثالث: الحواش → صافيتا
- يوم استكشافي
- زيارة برج صافيتا
- تفاعل محلي مميز

### اليوم الرابع: صافيتا → مشتى الحلو → حمام واصل
- مسار ساحلي
- اقتراب من البحر
- مناظر طبيعية جميلة

### اليوم الخامس: حمام واصل → طرطوس
- نهاية الرحلة
- الوصول إلى البحر
- حفل توديع
